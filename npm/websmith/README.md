# Websmith

Distribuzione npm in preparazione; non ancora pubblicata.

```bash
npm install -g @techreloaded/websmith
websmith version
websmith --help
```

Richiede Node.js 20+ e npm. Python e librerie sono inclusi nel motore della
piattaforma: non servono Python, pipx o Git per lavorare localmente.
Non usare `--omit=optional`. `websmith init` non è ancora implementato.
Il nome npm e il repository GitHub `techreloaded-ar/websmith-cli` sono indipendenti.
